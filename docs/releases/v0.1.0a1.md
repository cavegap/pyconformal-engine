# v0.1.0a1: thesis companion research preview

This prerelease brings the thesis-based Python examples and interactive
gallery into one reproducible teaching route. It is an experimental
research demonstration, with assumptions documented for each application.

## Three ways to start

- **Learn conformality:** Group P vector presets, curved paths and exact
  tangents, Cayley, exponential and logarithmic object examples.
- **Explore applications:** the fixed SC square, electrostatic potential,
  a second boundary problem for steady temperature, an ideal 50 Ω
  coplanar guide and a coplanar capacitive sensor.
- **Map the Moon:** the archived tracing from sphere to Mercator to a
  chosen transformation, and a unified Peirce atlas with imagery,
  hemisphere structure, relative scale and joined tiles.

The [thesis companion](../thesis-guide.md) links source passages to
examples. [Ten exercises](../exercises.md),
[separate worked checkpoints](../exercise-solutions.md) and
[reproduction commands](../reproducibility.md) support independent study.

## Validation

The local release candidate passed 308 Python tests and 38 reader
checkpoints. The shared browser maps were compared with Python on 36 SC
and 216 Peirce samples; the latter agreed within 3.54e-13 in normalized
coordinates. Four meridian-derivative references checked relative scale.
The publication build additionally checks every local navigation target
and HTML fragment. The CI workflow reports the current full test result
for this release commit; consult its result when reproducing the work.

## Scope

The SC map has fixed prevertices; this is not a general polygon solver.
Electronics examples assume ideal quasi-static uniform-dielectric models.
The thermal example uses steady isotropic conduction and varying
Dirichlet edge data. The archival lunar registration is approximate and
has no independent positional-uncertainty estimate. The Peirce atlas
uses a spherical Moon and a fixed central meridian of zero.

The historical Figure 4.5 text says z³, while the plotted contour agrees
with z². Both are retained and labeled. Newly reconstructed vector and
curve diagrams use explicitly stated example coordinates.

## Reproduce and contribute

```bash
python -m pip install -e ".[dev]"
python examples/reader_checks.py
python -m pytest
```

Open the [gallery](../../examples/index.html) from the complete checkout,
or build the portable public site with `python scripts/build_pages.py`.
The release's offline-gallery archive contains that static site; unzip
it and open `index.html`, keeping its directories together.

Use the [reader feedback form](https://github.com/cavegap/pyconformal-engine/issues/new/choose)
to report an unclear exercise or a reproducible numerical issue. See
[future work](../future-work.md) for bounded research proposals.
