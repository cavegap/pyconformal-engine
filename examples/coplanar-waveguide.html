Ideal coplanar transmission line

k = wt/(wt + 2s); k′ = √(1 − k²)
Z0 = η0 K(k′)/(4√εr K(k)); v = c/√εr; C′ = 1/(Z0 v)
K(k) = integral from 0 to π/2 of 1/√(1 − k² sin²θ) dθ

Here wₜ is the physical trace width (shown as w in the drawing), s is the gap on each side, and K uses the elliptic modulus k. C′ is capacitance per unit length, not a derivative with respect to z.

The equations above use the complete elliptic integral of the first kind, with its modulus convention stated explicitly.

F^{\prime}(\zeta)=\frac{A}{\sqrt{(\zeta-1)(\zeta+1)(\zeta-k)(\zeta+k)}}
\zeta=\frac{x+iy}{w_{\mathrm{t}}/2+s}

The four square-root factors come from the SC geometry. The model fixes the normalization and phase. The drawn line density is illustrative and does not measure field magnitude.

How to explore this example

  1. Edit dimensions

    Change width w, gap s per side, or relative permittivity. The drawing updates from these fields; its conductors are not draggable.

  2. Try 50 Ω

    Find 50 Ω gap adjusts s within the allowed range using the current width and dielectric. Then change permittivity to compare impedance.

  3. Read the colors

    The red signal strip is at 1 V; the blue grounds are at 0 V. Green curves and arrowheads show field direction.

The drawn density is illustrative. This is a uniform-dielectric, zero-thickness, ideal model; an actual PCB requires its stack-up and loss model.
