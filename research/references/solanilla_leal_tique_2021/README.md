# Solanilla, Leal y Tique (2021)

DOI: https://doi.org/10.3233/JCM-215014

Resumen editorial consultado: https://journals.sagepub.com/doi/abs/10.3233/JCM-215014

El resumen conecta inversas de funciones elípticas de Jacobi con toros y paralelogramos y plantea implementación numérica. Texto completo pendiente: no se atribuyen aquí teoremas, preguntas específicas ni resultados que no se hayan revisado.

La nueva aplicación clásica, sus fórmulas, límites y próximos pasos se documentan en [la nota técnica](../../riemann_torus/README.md). La referencia de Peirce de 2016 se conserva como antecedente.
