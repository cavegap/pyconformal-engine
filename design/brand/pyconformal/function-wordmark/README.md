# Firma activa: PyConformal con f matemática

Versión del 20 de noviembre de 2026. Esta es la dirección integrada en la web.

La palabra se lee PyConformal. Solo la f de Conformal usa el glifo matemático de función (U+1D453, Cambria Math); el resto de las letras parte de Georgia. El acento naranja destaca la función. Los originales se entregan como trazados SVG, por lo que la visualización no requiere instalar fuentes ni distribuir sus archivos binarios.

- wordmark-light.svg / wordmark-dark.svg: nombre con fondo transparente, para documentos y cabeceras.
- signature-light.svg / signature-dark.svg: sello Peirce y nombre en una composición autónoma.
- mark-light.svg / mark-dark.svg: símbolo con tangentes y punto proyectado.
- favicon.svg: sello sobre verde, usado también como icono de pestaña.

Los glifos siguen siendo trazados editables. El nombre accesible de la web conserva la escritura PyConformal. La biblioteca y sus citas mantienen PyConformal Engine. No se añade una firma «Hecho con Python».

El detalle matemático del símbolo está documentado en ../peirce-refined/. Las propuestas anteriores permanecen como bosquejos históricos. Colores principales: crema #F5EDDA, ciruela #321D39, mandarina #FF784E, verde de fondo #153D31.

Copias publicadas: web/landing/pyconformal-mark.svg y web/landing/pyconformal-wordmark-{dark,light}.svg. Cuando cambie la identidad, actualizar estos archivos y sus fuentes en conjunto.
