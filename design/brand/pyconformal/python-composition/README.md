# Firma PyConformal con referencia a Python

Composición editable en SVG, preparada el 20 de noviembre de 2026. La identidad activa de la web se conserva mientras se evalúa esta propuesta.

`signature-light.svg` y `signature-dark.svg` son archivos autónomos: incluyen el sello y el logo oficial mediante SVG anidado, sin imágenes remotas. El nombre sigue como texto editable (Cambria/Georgia); convertir a trazados antes de una entrega de imprenta si se necesita fijar la tipografía.

El símbolo de Peirce pertenece a la propuesta de identidad de PyConformal. El emblema de Python no se modifica ni se presenta como un diseño propio: aparece con la indicación «Hecho con Python» y la señal ™.

Origen del emblema oficial: https://www.python.org/community/logos/
Archivo descargado: https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg

Python y sus logos son marcas de la Python Software Foundation. La referencia indica la tecnología utilizada en el proyecto.

La marca pública es PyConformal. La biblioteca y su cita conservan el nombre PyConformal Engine.
