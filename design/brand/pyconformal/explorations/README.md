# Exploración de identidad 02

Dos bocetos vectoriales calculados con `examples/sc-square.js` y `examples/peirce-map.js`. Comparar con `comparison.html`. La identidad activa de la web no se modifica.

- Atlas vivo: proyección completa, paralelos −35°, 35°, 65°; meridianos −160°, −70°, 20°, 110°; ecuador destacado.
- Órbita abierta: hemisferio norte, paralelos 27° y 57°; meridianos −150°, −60°, 30°, 120°; meridiano −22° destacado.
- Punto en longitud −22°, latitud 31°.

`generate.cjs` conserva el bosquejo programático. Para regenerar en otra ubicación, ajustar la variable root al repositorio. Los SVG resultantes no dependen de JavaScript ni de fuentes.
